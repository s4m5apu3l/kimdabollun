# KIMDABOLLUN

**Ким да буоллун** — «кем бы ни был» / «любой может быть».

Одиночная 2D action roguelite с пиксельной графикой на Godot 4. Мир — якутская мифология, северная тайга, духи и холодный свет. Боевой цикл вдохновлён *Hades*, но персонажи, сюжет и визуал — оригинальные.

> Статус: **ранний прототип**. Играбельного билда пока нет — идёт сборка каркаса.

---

## О проекте

| | |
|---|---|
| **Жанр** | Single-player 2D Action Roguelite |
| **Движок** | Godot 4.7 |
| **Язык** | GDScript |
| **Графика** | Pixel Art, 3/4 top-down (не строгая изометрия) |
| **Платформа** | Windows PC (первая цель) |
| **Мультиплеер** | Нет и не планируется в MVP |
| **Сетка** | 960 × 540, тайл 32 × 32, окно 1920 × 1080 (×2) |

Все размеры спрайтов, тайлов и комнат — в [docs/ASSET-SPEC.md](docs/ASSET-SPEC.md).

Игровой цикл: убежище → выбор комнаты → бой на арене → награда и улучшение → элита или босс → возврат в убежище с постоянным прогрессом. Смерть — часть цикла, а не потеря всего.

## Как запустить

1. Установить [Godot 4.7+](https://godotengine.org/download).
2. Открыть `project.godot` в редакторе.
3. Нажать **F5**.

В репозитории уже лежит аддон `addons/godot_ai` (Godot AI 3.1.5, MIT) — редактор автоматически поднимет его MCP-бэкенд через `uvx`. Для самой игры аддон не обязателен, он нужен только для работы с ИИ прямо в редакторе.

## Структура

```text
kimdabollun/
├── project.godot          # конфигурация проекта
├── scenes/                # сцены: арена, герой, враги, UI
├── scripts/               # GDScript-логика
├── data/                  # ресурсы: улучшения, параметры врагов
├── assets/                # спрайты, тайлы, звук
└── addons/godot_ai/       # инструменты Godot AI (не часть игры)
```

## Принципы

- Сначала маленький качественный прототип, потом контент.
- Читаемые телеграфы атак и отзывчивое управление важнее количества механик.
- Арт — сначала готовые бесплатные ассеты и заглушки, уникальный арт позже.
- Никакого копирования защищённых элементов *Hades*.
